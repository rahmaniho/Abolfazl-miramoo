# 📥 پوشه‌ی ارسال فایل

فایل‌های لوگویی که در گفت‌وگو می‌فرستید (یا خودتان اینجا کپی می‌کنید) در این پوشه
قرار می‌گیرند تا ابزار `tools/make-logo.py` آن‌ها را خودکار پیدا کند.

روند کار:

```bash
# ۱) فایل‌های لوگو را در همین پوشه بگذارید (هر نامی، PNG یا JPG)
# ۲) ابزار را اجرا کنید — بزرگ‌ترین فایل را به‌عنوان منبع برمی‌دارد
python3 tools/make-logo.py

# یا مسیر را دستی بدهید:
python3 tools/make-logo.py --src uploads/logo.png
python3 tools/make-logo.py --src uploads/logo-navy-on-light.png --mode light
```

خروجی‌ها در `assets/img/` ساخته می‌شوند و همان نام‌های فعلی سایت را بازنویسی می‌کنند،
پس هیچ تغییری در HTML/CSS لازم نیست. برای بازبینی، `assets/img/logo-preview.png` را ببینید.

> نکته: محتوای همین پوشه در مخزن گیت نادیده گرفته می‌شود (به‌جز همین فایل راهنما)
> تا فایل‌های سنگین منبع، مخزن را بزرگ نکنند. فایل‌های نهایی در `assets/img/` ذخیره می‌شوند.
